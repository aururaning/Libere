# Libere 0.6.10 · 大资料库切换优化

版本 0.6.10（build 22），2026-11-20。

## 本次更新

- 改善页面、文件夹较多时，打开与切换笔记的等待。
- 侧栏和文件目录共用已计算的层级结果，减少重复扫描；文件夹卡片只读取需要显示的摘要。
- 切页时只检查当前页面和已打开编辑器涉及的引用文件，不再逐一检查整份资料库的文件。
- 打开长页时优先加载当前区域和附近的内容，其他内容随滚动加载；已加载内容在本页内保持，保留编辑和附件滚动状态。
- Mac 安装包启用优化编译，并包含此前仅在本机提供的“移动到”菜单性能修复。

## 安装

下载 **Libere-0.6.10-arm64.pkg**，退出旧版后双击安装，再从“应用程序”打开 Libere，继续使用原来的资料库。

适用于 **Apple Silicon（M 系列）Mac、macOS 14 及以上**。安装包和校验文件见 [Release](https://github.com/aururaning/Libere/releases/tag/v0.6.10)。

此版本未改变资料格式、原始附件、手写与文字吸附规则。锁定 PDF 的位置、大小和预览页保持固定。

当前包尚未经过 Apple 发行签名和公证；未提供 Intel 或 iPad 安装包。
