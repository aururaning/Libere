# Libere 0.7.3

版本 0.7.3（build 32），2026-11-27。

## 本次更新

- 修复 iCloud 文件已下载却仍显示「正在下载」的问题。应用跟踪最新下载状态，完成后恢复预览；在 Finder 下载的文件也会重新检查，并提供「重新检查」按钮。
- 修复文件夹选中蓝底下的展开箭头，文件夹页右上角新增「子文件夹」。
- 移除「文字」旁容易误认的格式图标，格式继续在右侧面板调整。
- 修复 Markdown 编辑/预览按钮的点击区域、编辑字号和字体；补充直和、逐元素乘积、张量积、转置、伴随及相关常用 LaTeX 语法。
- 修复 Mac 随航 Pencil 书写，手指继续用于浏览；选择模式下点其他块切换选择、点空白取消选择。移除手写模式底部常驻提示。
- 后续只维护 Mac 版，iPad 作为随航屏幕和 Pencil 输入设备。

此前侧栏整树复制/移动、文字与文件快捷键、真实原件移动、引用和撤销功能保留，资料库格式仍为 3。

## 验证

199 项 XCTest、2215 项优化编译原生检查、18 项桥接测试和 Mac SDK 构建通过。用户已在随航设备上确认书写、浏览和选择操作全部正常；笔迹保存后重新解码通过。正式安装包已逐文件解包比对，调试输入记录未进入正式程序。

## 安装

保存并退出旧版及独立测试窗口后，安装 Libere-0.7.3-arm64.pkg。适用于 Apple Silicon Mac、macOS 14 及以上。正式入口仍为「应用程序」中的 Libere。

公式为离线支持的 LaTeX 子集，不支持的语法保留原文。实际 iCloud 账号下载、跨设备联动和 live HTTP/MCP 未在本轮验收。安装包为临时签名，尚未经过 Apple 公证；本轮未替换或重启用户正式应用。
