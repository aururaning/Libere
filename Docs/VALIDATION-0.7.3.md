# Libere 0.7.3（build 32）验证

2026-11-27。199 XCTest、2215 项优化编译原生断言、18 项桥接测试和 macOS SDK 构建通过。优化发行可执行文件通过严格签名校验，打包后逐文件解包比对。

- iCloud 新增 15 项下载完成、外部下载、异步顺序与晚到错误检查，覆盖当前/未知元数据、缓存刷新、重新加载和下载中不重复请求。实际 iCloud 账号上的下载没有在本轮自动验收。
- 新增 22 项原生交互检查覆盖所选侧栏箭头、Markdown 原生按钮命中、编辑字体与随航直接触摸路由；新增 12 项笔输入检查，覆盖纯 tablet 事件、鼠标/触控板不凭压力落笔及抬笔保存。AppKit 的识别器状态由输入分发时提交，测试用即时状态适配器核对状态转换，没有向系统桌面合成输入。
- 新增 3 个公式核心测试；19 项 WebKit 公式排版及 3 项间距检查通过。截图中的直和、逐元素乘积、张量积、转置与伴随显示已检查。
- 用户在独立随航测试应用中确认「全部正常」。输入记录核对了 A/B 内容块切换和空白处清除选择，笔画记录有 15 次开始/结束；重开后从磁盘解码出 23 笔、1098 个点、29170 字节。输入日志有采样上限，15 次事件并不代表全部笔画。测试应用后来重启覆盖了活动日志，验收摘要保存于 sidecar-build32.json。正式版未编入 LIBERE_INPUT_TRACE。
- 子文件夹按钮的创建闭包及原生布局已检查；离屏截图有动态高亮黑色伪影，不能作为真实窗口视觉验收。后续 ScreenCaptureKit 抓取失败也未计入通过项。

主证据：check-0.7.2-build32.log、native-0.7.2-build32.log、build-mac-0.7.2-build32.log、update32-native.log、formula-build32.log、math-build32.log、sidecar-build32.json 和 build32-source-manifest.json。原始笔迹与输入记录只保留在本地隔离测试库，不公开发布。

依用户决定，后续只维护 Mac 版；iPad 用作随航屏幕。此前 iPad SDK 构建记录属于历史版本，本轮不计入验证。没有替换或重启用户正式应用。真实 iCloud 跨设备、目录授权选择器及 live HTTP/MCP 未在本轮验收；安装包仍未经过 Apple 公证。

本轮功能回归与设备验收完成后，按用户要求将发布版本号从0.7.2改为0.7.3；功能源码和资源未变。0.7.3另外重新执行Mac构建、优化编译、严格签名和安装包解包比对。旧日志名称中的0.7.2-build32表示验收时的版本号，不是最终安装包版本。
