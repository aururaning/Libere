## 功能更新

- Mac 画布支持直接粘贴任意类型的普通文件、多文件、剪贴板图片和 PDF，落点使用鼠标位置；缩放和滚动后位置保持准确。
- 库外文件后台复制到当前页面文件夹并按类型分类，同名自动编号；库内原件和应用内文件复制继续共用同一原件。
- 应用内整块复制保留原页面和内容块定位，右键“前往原位置”可跳回来源。普通文字块保留来源定位，文字内容可各自编辑。
- 不支持内嵌预览的文件显示通用卡片，可通过系统应用打开。粘贴本身不会执行文件。
- 功能教程按功能分组，支持搜索与逐项操作说明。首次使用可自动显示；覆盖升级不会重复弹出，也不会自动插入或恢复示例页面。页面右上角问号和“笔记 → 功能教程”始终可手动打开。

## 文件与撤销

- 外部原文件保持不变；没有新增资料库格式迁移，格式仍为 3。
- 粘贴归档是一次性入库，不创建编辑工作镜像。已有“添加文件索引”仍采用库内路径索引方式。
- 归档过程中切页不会串页；页面改名、移动与伴随资料目录保持一致。一次撤销移除整组内容块，归档原件保留供重做和恢复。
- 文件夹或文件包仍不作为普通文件粘贴；未提供原路径或文件数据的剪贴板承诺需要先完成下载或导出。

## 使用

复制文件后，将鼠标放到笔记画布上按 ⌘V。复制应用内整个内容块时自动建立来源引用；复制文字选区后，在文字编辑器内粘贴仍为原生文字粘贴。

旧示例内容及用户修改保持原样。需要场景示例时，从“笔记 → 示例场景”手动打开。
