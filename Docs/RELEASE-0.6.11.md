# Libere 0.6.11 · 启动、原文件索引与滚轮修复

版本 0.6.11（build 23），2026-11-20。

## 使用变化

- 启动时先显示界面，后台读取索引。启动和回到应用时只检查当前页面及已打开编辑器涉及的文件，不逐项检查全库文件，也不自动重建工作目录。
- 先手动将原文件放入资料库文件夹，再使用“添加文件索引”。加入仅登记路径；编辑直接保存原文件，不生成附件、工作镜像或每次编辑快照。文件夹外的路径及越界符号链接会被拒绝。
- 侧栏同时管理原文件：改名或移动文件页面、文件夹时移动所属原件，更新跨页引用及打开的编辑器/Notebook 工作路径。遇到同名目标会保留双方文件；保存失败回滚，移动支持撤销/重做和重启恢复。仅引用其他页面文件的位置继续共用来源原件。
- Mac 上没有选中块时，滚轮只滚动外层页面；选中可滚动块后，滚轮交给该块，到顶/到底都不传给外层。普通画布、目录内容块、文件夹介绍与场景首页采用同样规则。
- “导出索引与批注”保留页面、文字、手写和相对路径，不打包原文件。搬迁时移动整个资料库文件夹。HTML 临时预览只保存在内存中；需要文件时由用户明确导出。
- Agent 使用 `file` + `filePath` 登记资料库内原文件，MCP `import_file` 也只转发路径。Base64 附件上传被拒绝，同路径引用共享同一文件身份。

旧资料库升级为格式 2。已有旧附件和镜像转为指向现有文件的索引，旧版本文件保留，不自动删除；旧应用不能写入新版格式。新场景示例不再向资料库复制文件素材。

手写不参与吸附或自动排版；文字批注锚点及锁定 PDF 的框、预览页保持原规则。

## 安装

适用于 Apple Silicon Mac、macOS 14 及以上。退出旧版后安装 **Libere-0.6.11-arm64.pkg**，继续打开原资料库文件夹。

安装包采用本地临时签名，尚未经过 Apple 发行签名和公证。iPad 的编译检查不等同于设备触摸交互验收。
