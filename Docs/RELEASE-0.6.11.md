# Libere 0.6.11 · 原文件直连与文件管理

发布日期：2026-11-20（build 23）

## 更新内容

- **启动更快**：打开应用时直接进入界面并在后台读取索引，不再每次启动都把整个资料库文件扫一遍。
- **原文件直连，不拷贝副本**：把文件放进资料库文件夹后点“添加文件索引”，软件只记录相对路径，编辑直接保存原文件，不再额外复制一份占硬盘空间。
- **侧栏即文件管理**：在侧栏重命名或移动文件夹/页面时，磁盘里的原文件和文件夹会同步移动并更新所有跨页引用，支持同名保护与 `⌘Z` 撤销。
- **更自然的分层滚轮**：没选中内容块时滚轮滚整页；选中可滚动内容块后，滚轮只滚它内部的内容。
- **轻量备份**：导出功能只保存索引、文字、手写和批注，不再打包原文件；迁移资料库直接移动整个文件夹即可。

> 注：0.6.11 起资料库索引格式升级为第 2 版。

## 安装

退出旧版后安装 **Libere-0.6.11-arm64.pkg**，适用于 **Apple Silicon（M 系列）Mac、macOS 14 及以上**。
