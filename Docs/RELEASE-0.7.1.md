# Libere 0.7.1 · 阅读器折行与单元格撤销修复

版本 0.7.1（build 27），2026-11-24。

- Inspector 的“阅读与页内批注”和画布、双击、搜索入口统一使用同一个阅读窗口；Mac 移除旧阅读 sheet，重复打开同一文件块不会产生第二个阅读器。
- Notebook/源码阅读区放大后按当前可视宽度重新折行，工具栏保持原尺寸，避免按100%宽度放大而导致右侧超出窗口。
- Notebook 插入、删除、移动其他单元格及末尾 Shift+Enter 时，保留未受影响单元格的原生编辑器、选区和文字撤销记录。删除、转换或撤销替换内容时，只更新受影响单元格；迟到回调仍按稳定身份校验，不写入别的单元格。

退出旧版后安装 **Libere-0.7.1-arm64.pkg**，继续使用原资料库。适用于 Apple Silicon Mac、macOS 14+。资料格式仍为3，本版不增加资料库格式迁移。

安装包尚未经过 Apple 发行签名和公证；原生测试和SDK编译不代表全部真实设备手感或iCloud双设备已验收。
