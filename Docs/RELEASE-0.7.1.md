# Libere 0.7.1 · 阅读器与 Notebook 细节修复

发布日期：2026-11-24（build 27）

## 更新内容

- **阅读窗口入口统一**：从右侧属性栏点“阅读与页内批注”，现在和双击附件一样会复用同一个独立阅读窗口，不会再重复弹出第二个窗口。
- **代码 / Notebook 放大不裁切**：在阅读窗口里放大看源码或 Notebook 时，文字会按当前窗口宽度重新折行，顶部工具栏保持原大小，不用再左右拖滚动条看一行代码。
- **Notebook 编辑更稳**：插入、删除、移动其他单元格或按 `Shift + Enter` 新增单元格时，不会再重置正在编辑的那一格，光标位置和文字撤销（`⌘Z`）都会完整保留。

## 安装

退出旧版后下载并安装 **Libere-0.7.1-arm64.pkg** 即可，原有资料库和笔记会自动保留。支持 **Apple Silicon（M 系列）Mac、macOS 14 及以上**。

> 提示：当前安装包为个人自签名，如首次打开遇到系统提示无法验证开发者，请在「系统设置 → 隐私与安全性」点击“仍要打开”。
