# Libere 0.6.12 · 侧栏滚轮与展开按钮修复

版本 0.6.12（build 24），2026-11-21。

- 修复在侧栏滚动时，主页面或选中的内容块跟着滚动的问题。画布与文件夹首页均按鼠标实际命中的可见区域接收事件；侧栏覆盖页面时也不会把输入交给后面的页面。
- 扩大侧栏展开、收起按钮的点击区域：Mac 为 28×30 点，箭头四周空白均可点击；iPad 为 44×44 点。点击只展开或收起子项，不切换当前页面。
- 主页面内继续采用原有规则：未选块时滚外层；选中可滚动块后滚该块，到顶或到底也不传给外层。

退出旧版后安装 **Libere-0.6.12-arm64.pkg**。适用于 Apple Silicon Mac、macOS 14 及以上。

文件索引与原文件管理规则保持不变。本版未新增数据迁移。安装包仍采用本地临时签名，尚未完成 Apple 发行签名和公证；设备上的鼠标/触控板手感仍需实际试用确认。
