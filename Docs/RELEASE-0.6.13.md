# Libere 0.6.13 · 文本选择、公式与 iCloud 自动省空间

发布日期：2026-11-23（build 25）

## 更新内容

- **框内全选更顺手**：选中文本框后按 `⌘A` 会自动进入编辑并全选框内文字；正在打字或搜索时，只全选当前输入框，不会误选中整张画布。
- **编辑时不误触拖动**：编辑文本时，边框不再挡住鼠标选字，拖移改走框外侧的移动手柄。
- **Markdown 公式加强**：同时支持 `$…$`、`$$…$$`、`\(...\)` 和 `\[...\]`，修好了数学下划线与斜体、公式竖线与表格、代码块之间的冲突，补齐常见字体、上下限和矩阵写法。
- **自动释放 iCloud 本地缓存**：在“存储位置”设置新增开关，7 天没看过的 iCloud 文件会自动释放本地下载以节省硬盘空间；云端原文件、索引和批注都会保留，想看时点击“下载文件”即可。

## 安装

退出旧版后安装 **Libere-0.6.13-arm64.pkg**，适用于 **Apple Silicon（M 系列）Mac、macOS 14 及以上**。
