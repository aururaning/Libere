# Libere 0.6.13 · 文本选择、公式与 iCloud 本地空间

版本 0.6.13（build 25），2026-11-23。

- 选中文本块后按 ⌘A，会进入编辑并全选框内内容；已有焦点的正文、源码、搜索框等保持各自全选范围，不会全选整个画布。
- 编辑文本时，顶部与边缘的拖动层不再挡住文字选择；外侧移动手柄仍可使用。
- Markdown 支持 `$…$`、`$$…$$`、`\(...\)`、`\[...\]`，修复数学下划线与强调、公式竖线与表格、代码围栏之间的冲突。补充常见公式字体、重音、上下限、矩阵及文本间距，保留目录链接的转义标题。
- 新增“自动释放 7 天未查阅的 iCloud 文件”开关（存储位置设置）。只释放已上传完成、没有冲突、未使用的本地下载，保留云端原件、索引和批注。查看云端文件时，在预览内点击“下载文件”。
- 正在编辑、下载、上传或被活动 Notebook 工作目录使用的文件受到保护。首次登记从登记时开始计时；关闭长期打开的预览后重新计时。维护只分批检查索引中的旧候选，不扫描资料库目录。

109 项 XCTest、1430 项原生检查、18 项桥接测试和三个 Apple SDK 构建通过；离屏 WebKit 验证了 8 个公式布局和 3 个空白宽度案例。

退出旧版后安装 **Libere-0.6.13-arm64.pkg**；支持 Apple Silicon Mac、macOS 14+。原件索引、文件移动/撤销与选择驱动滚轮规则保持。

自动释放仅在 Libere 处于前台时检查。真实 iCloud 账号的下载/释放和设备交互尚未实测；公式仍为离线 LaTeX 子集。安装包尚未完成 Apple 发行签名和公证。
