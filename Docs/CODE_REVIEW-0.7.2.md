# 0.7.2 build30 代码检查

本轮检查覆盖全部80个生产Swift文件（14438行）的声明、引用与完全重复文件扫描，并逐段检查画布指针、滚轮、PDF/批注、标题焦点、侧栏层级、文件移动、索引保存和访问元数据的调用路径。

## 已完成的清理

- 删除无生产、测试或脚本调用的 AttachmentPreview 和 zoomableEditor，移除旧 PDFState / PDFPreview / PDFNativeView 分支，保留实际使用的附件纸面与原生PDF文字层。
- ClipboardPlacement统一普通粘贴和移动的落点计算；updateActiveFileLocations统一侧栏移动与剪贴板移动后的活动路径更新。
- 原生按钮与拖柄各自拥有实际边界；一次按下只解析一次目标，拖动和松开沿用同一捕获，避免多个事件入口争夺。
- 将散落的仓库保存改为persistWorkspace；内容与磁盘标记均未变化时跳过重读与重写，磁盘变化时仍经过正常持久化检查。
- 移除已经为空操作的工作目录同步调用；文件继续索引原件，不产生编辑镜像。
- 访问记录从UserDefaults移到本机专用文件，串行异步保存并跳过无变化写入；旧数据确认保存后才清除旧偏好值。
- 收敛重复粘贴坐标逻辑并修复主线程回调的编译警告。

## 保留的行为约束

保留文件哈希/身份校验、目标冲突检查、原件完整性、先保存索引与撤销记录再删除源、设备本地恢复凭据、标题组合输入提交和失败保留。它们分别对应可复现的数据完整性或交互条件。兼容接口及系统动态回调不能仅凭文本引用次数删掉。

## 验证范围

188个XCTest、2125项原生断言、18项桥接测试及三个Apple SDK构建通过。引用扫描用于发现候选，不等同于静态证明全部代码可达，也不意味着排除了所有潜在缺陷。实际触控板三指手感与真实iCloud跨设备需要独立验收。
