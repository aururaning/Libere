# 画布、文件与批注

## 选择、编辑与拖动

在选择模式中，单击内容块会选中它；双击或点击“编辑”进入文字编辑。点击空白或另一个块时提交当前编辑并退出输入。

选中内容块后，使用框外的四向拖柄移动整块；编辑文字时同样可以拖动。右下角手柄调整大小。纯文本内容超过框高时向下延伸，改变宽度时重新换行。按 Delete 删除选中的块，⌘Z 撤销。

画布的缩放改变显示比例，不修改已保存的内容坐标。空白处用于取消选择，不应选择最近的块。

## 文件夹与页面

页面和文件夹都可以包含子页面。侧栏可重命名、拖动层级、移动到回收站和恢复。文件夹首页点击“编辑介绍”，可以输入 Markdown、插入分类标题、列表和子页面链接；“插入目录”生成当前子页面的链接列表。

文件夹介绍保留用户主动清空的状态，不会因为内容为空而自动恢复默认文案。场景展示中的文件夹也可以编辑。

## 导入与阅读

使用工具栏的“导入文件”加入 PDF、图片、Markdown、HTML、Notebook 和支持的文本/源码文件。附件原件按字节保留，引用可以复用同一文件；各处的显示框和批注独立。

图片支持 PNG、JPEG、HEIC/HEIF、GIF、TIFF、BMP 与 WebP。预览处理图片方向和透明度，长图可以滚动；GIF/TIFF 显示首帧。图片原件不会因预览而重编码。

附件标题栏的箭头切换收起和展开；最近展开的文件显示在更上层。预览无法完整显示内容时，滚轮先滚动附件纸面及其页内批注。双击附件可打开阅读窗口。

PDF 的画布预览页与阅读窗口当前页分别保存使用状态。锁定 PDF 固定预览框和预览页，仍可阅读和批注。阅读窗口翻页不会改变锁定的画布预览页。

Markdown、HTML、源码和 Notebook 支持编辑。Notebook 保留已保存的代码和输出；Mac 可连接用户选择的 Python 环境执行，iPad 当前用于查看和编辑。

## 页内文字与手写

在阅读器的文字批注模式中，双击页面空白处添加文字批注。使用文字框把手移动批注；单击不会直接新增。

| 批注位置 | 保存的坐标 | 翻页与移动时的行为 |
| --- | --- | --- |
| 附件页内手写 | 附件块、页码和文档页坐标 | 随所属页显示，与页面一起缩放 |
| 附件页内文字 | 同页的文字列表与位置 | 随所属页显示，与纸面一起滚动 |
| 画布手写 | 整张笔记的画布坐标 | 保持画布位置，不随附件移动 |
| 页外文字分支 | 相对批注点及画布框 | 依照与父块的关联更新位置 |

PDF 使用各页的文档坐标；图片和非分页附件使用固定宽度的连续纸面。批注与附件内容共用滚动区域，滚动本身不改变文档坐标。备份包含这些独立的数据层。

## 页外批注点与文字分支

为资料放置批注点后，可以创建相关的文字框。点可以位于资料框外，并独立设置文字的对齐边。拖动文字靠近可用批注点时显示对齐提示；松手建立关联，拖离可以解除关联。

批注点相对于所属内容块保存位置，不是 PDF 内部字符位置。移动或缩放父块时，关联分支按父子顺序更新；如果需要移动锁定块或造成不允许的越界，调整会取消。删除父块不应删除下级文字内容。

## 手写模式

手写层只在手写模式中接收相应输入。原生 iPad 使用 PencilKit；手指用于浏览，Pencil 用于落笔。Mac 使用支持的数位笔事件，并可通过随航使用 Pencil。两端使用 `PKDrawing` 存储手写。

**手写永不参与吸附或自动排版。** 画布手写和附件页内手写分开保存，不能因移动文字框或“整理版面”而移动笔迹。随航输入方式与设备检查见 [SIDECAR.md](SIDECAR.md)。

## Markdown、公式与布局

文字框支持 Markdown 编辑与预览。`$…$` 为行内公式，`$$…$$` 为独立公式；代码中的美元符号保持原样。公式无法解析时保留原文并提示错误。

“整理版面”是显式操作，不会因为普通编辑自动触发。带手写、锁定资料或批注关联的内容受排版保护。添加新内容时尽量使用点击位置和附近空位，不能重新安排已有手写。

## 保存、备份与同步

编辑提交、翻页、导航及退出会处理当前输入和保存。原件、附件引用、介绍文字和批注进入资料库备份。CloudKit 为可选配置，见 [ICLOUD.md](ICLOUD.md)。

同步使用版本信息区分后续修改与并行修改；并行编辑可能产生可编辑的冲突副本。收到旧上传回执不能把后续编辑误判为已同步。回收站保留可恢复的删除状态。

实际键盘焦点、中文输入法、系统文件权限、触控与多设备行为仍需要在目标环境中验收，检查清单见 [VALIDATION.md](VALIDATION.md)。

## 0.6.11：原文件索引、文件管理与 Mac 滚轮

文件加入只登记当前资料库内原件路径。请先手动放入文件，再选择“添加文件索引”；编辑直接保存原文件，不创建附件、工作镜像或逐次编辑快照。侧栏改名和移动同步移动所属原文件，全部引用与已打开编辑器随路径更新，支持撤销和失败回滚。

无选中块时，页面内所有滚轮输入都滚动外层；选中可滚动块时先滚动该块，到顶/底后继续向该方向滚动外层（0.7.2 build30 起）。相同规则覆盖文件夹介绍/目录和场景首页，切页清除选择。

当前“导出索引与批注”不包含原文件。搬迁时保留整个资料库文件夹。已有旧文件只迁移索引，不自动删除各份旧内容；新示例不再复制文件素材。

## 0.6.12：侧栏区域和展开按钮

侧栏滚轮只影响侧栏，主页面或选中块不会接收被侧栏覆盖区域的输入。展开/收起箭头的周围空白可点击；Mac 点击区域为 28×30 点，iPad 为 44×44 点，操作不切换当前页面。

## 0.6.13：文本与 iCloud

选中文本框后 ⌘A 进入编辑并全选；编辑时框内边缘让给文字选择，外侧拖柄仍可移动。公式支持美元与反斜杠两组行内/独立定界符。存储位置设置内可开关“自动释放7天未查阅的iCloud文件”；只释放本地下载，不删除云端原文件，预览可点击下载。首次登记从登记日起计算；维护在应用前台运行时进行。

## 0.7.0：快捷操作

- ⌘K 搜索笔记正文、公式、文件名、链接、标签和页内文字批注，回车跳转并定位。搜索不会读取原文件或触发下载。
- 输入 [[ 补全稳定页面引用；页面下方“标签与引用”查看反向链接。
- Shift 单击或拖动空白框选（iPad 长按后拖框），使用浮动工具条批量锁定、删除、对齐/分布，拖动选中组整体移动；手写不参与。
- Finder 拖入库内文件建索引；未编辑文字时 ⌘V 自动识别文字、链接和库内文件。
- Markdown 预览可 ⌘单击链接，或切换“链接交互”后直接点击。链接块内部按钮/网页可直接操作。
- 阅读器默认独立窗口，同一文件块重复打开复用；可切全屏、输入页码或用方向键/空格翻页。Notebook/源码仅正文缩放。
- Notebook 的单元菜单可插入、删除、移动、转换和清输出；Shift+Enter运行并推进焦点，运行中不能改源文。
- 回收站永久清除需确认，原文件保留；格式3防止旧备份/撤销/迟到同步复活已清记录。旧版不能写入新版格式。
- 当前页可批量预下载/释放iCloud下载，正在使用、未上传和冲突文件保持本地。


## 0.7.2：鼠标位置粘贴与自动归档

- 在 Finder 复制一个或多个文件，把鼠标放到笔记画布上后按 ⌘V。第一块左上角落在指针位置，其余文件向下排列；缩放、滚动和居中画布均换算到纸面坐标。此时不自动寻找空位，不移动现有内容或手写。
- 库外文件复制一次，按 PDF、图片、Notebook、Python、Markdown、网页、数据、文档、音视频、压缩包、文本与源码或其他归入当前页面文件夹。同名新文件自动编号，不覆盖已有文件，复制过程在后台进行。
- 库内文件复用原件路径和文件身份。应用内整块复制保留原页面、原内容块的引用，右键“前往原位置”可跳转并定位；文件共用内容，普通文字块保留来源定位并各自编辑。
- 没有文件路径的剪贴板 PNG/JPEG/TIFF/HEIC/GIF 图片和 PDF 可保存为新原件。没有原路径也未提供文件内容的文件承诺，须先由原应用完成下载或导出。
- 未知扩展名、无扩展名、Office、压缩包及音视频均可作为文件卡片。现有可预览格式继续原生预览；其他格式通过“打开原文件”交给系统应用，不会因粘贴而自动执行。
- 已进入文字编辑器的普通文本粘贴仍落在文字光标处。主画布中的整块/文件剪贴板会建立内容块；独立阅读窗口保留其编辑器的原生粘贴行为。
- 通过菜单粘贴且指针离开纸面时，使用本页最后一次纸面指针位置；没有记录则使用可视区域中心。切换页面会清除旧页位置。
- 归档期间切换页面不会改变目标；改名或移动目标页后使用新位置完成归档。文件夹介绍页粘贴文件会创建子页面。一组粘贴可一次撤销，已归档原件保留供恢复和重做。
- 页面右上角问号或“笔记 → 功能教程”打开分组功能说明，可搜索操作和快捷键。首次使用用右上角浮层提示问号入口，点击后才打开教程；覆盖升级不重复提示；教程本身不写入资料库。旧示例和用户修改保留，“笔记 → 示例场景”是手动添加或打开示例的入口。


## 0.7.2 build30：移动、焦点与 PDF 操作

- 在 Finder 或 Libere 复制文件/内容块后，按 ⌘⌥V「移动到这里」。库外原文件移入当前页分类文件夹；库内文件更新原路径与所有引用，应用内移动只移除所选原块。鼠标仍决定画布落点。
- 文件传输校验成功、索引与撤销记录保存后才移除原位置；同名目标拒绝移动。撤销/重做会移动最新原件，不恢复旧内容快照。失败时保留原件或已经完成的归档文件，可从菜单检查未完成移动。恢复凭据只保存在本机。
- 编辑顶部或侧栏标题后点击画布，先提交标题再把键盘交给所点区域；中文组合输入、改名冲突不会被丢弃。
- 在画布选中 PDF、文件等特殊块后可用 ⌘Delete 删除所选块；编辑文字时保持编辑器自己的删除含义。锁定块和磁盘原件不会被这一快捷键删除。
- 侧栏把页面/文件夹拖到文件夹行中部即可嵌套，拖到行上/下边缘调整顺序；原文件、跨页索引和活动编辑路径一起更新，支持撤销。
- PDF 预览保持原生选字层，画布缩放只作用一次；独立阅读窗口的缩放不改变画布预览。页内批注预览、编辑器和按钮使用同一文档比例。
- 块右上角折叠与阅读按钮使用完整可点击区域；移动拖柄按实际显示边界捕获按下、拖动和松开，不再转成画布框选。
