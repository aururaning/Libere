## 新增工作流

- **⌘K 搜索/跳转**：搜索所有笔记正文、公式、文件名、链接、标签和页内文字批注；结果定位到对应页与块。搜索不读原文件、不触发 iCloud 下载。
- **页面引用**：输入 `[[` 提供候选，插入稳定页面链接；详情底部可查看标签和反向链接。
- **画布多选**：Mac Shift 单击、空白拖框；iPad 空白长按后拖框。支持整组移动、删除、锁定/解锁、对齐与等距分布，一次撤销。自动排列继续保护手写、锁定和关联批注。
- **快速添加**：Finder 拖入资料库内文件建立索引，拖到文件夹可创建索引子页；画布未编辑文字时，⌘V 可识别链接、普通文字和库内文件路径。库外文件不会被复制。
- **PDF 阅读**：输入页码跳转；非文本输入时可用方向键、空格/Shift+空格翻页。阅读翻页不修改锁定画布预览页。
- **批注连线**：父锚点与子块之间显示细虚线，可在“笔记”菜单切换。
- **回收站管理**：显示摘要、删除时间和原路径；可确认后永久清除单项或清空。只清除页面/批注记录，原文件保留；旧备份、撤销、迟到保存和同步不能复活已清除页面。
- **文件夹主页**：子项卡片右键菜单；空文件夹可新建子笔记、子文件夹或引用文件。
- **Notebook 单元**：插入 Code/Markdown、删除、上下移、类型转换、清除输出、结构撤销；Shift+Enter 运行并推进焦点。
- **iCloud 状态**：折叠标题显示云端下载状态；可预下载当前页文件或安全释放当前页未使用的本地下载。上传、冲突、编辑、预览与运行中内核保护继续生效。

## 安装与验证

退出旧版后安装 **Libere-0.7.0-arm64.pkg**，继续打开原资料库。适用于 Apple Silicon Mac、macOS 14+。

132 项 XCTest、1568 项原生检查、18 项桥接测试及 Mac / iPad Simulator / iPad 设备 SDK 构建通过。原生检查覆盖真实 NSTextView 输入法、生产按钮、WKWebView 链接及窗口关闭保存顺序。

本版资料格式升级为 **3**，兼容读取并升级 1/2；旧版不能继续写入新格式。永久清除不可撤销，但不会删除原文件。自动 iCloud 释放仅在应用前台检查，首次登记后计时。真实 iCloud 双设备、Pencil/Sidecar 与设备操作手感未实测；安装包未经过 Apple 发行签名或公证。
