# Libere 0.7.0 · 全局搜索、双链、多选与交互全面修复

发布日期：2026-11-24（build 26）

这是一次比较大的功能与体验升级，集中补齐了搜索跳转、双链、画布多选和一批日常编辑里的交互卡点。

## 新增功能

- **`⌘K` 全局搜索与快速跳转**：支持搜索所有页面的正文、公式、文件名、链接、标签和 PDF 页内文字批注，选定结果后直接跳转到对应页面和内容块。
- **页面双链与标签**：编辑时输入 `[[` 可以快速联想并插入其他页面的链接；页面底部新增标签和反向链接列表，方便顺着引用来回看。
- **画布多选与批量整理**：支持 `Shift + 单击` 或在空白处拖框多选内容块，可以一起拖动、锁定/解锁、删除、对齐（左/右/顶/底/居中）和等距分布；批注分支之间新增虚线连线（可在“笔记”菜单开关）。
- **Finder 拖入 & 智能粘贴**：把资料库文件夹里的文件直接从 Finder 拖进画布就能建索引，拖进文件夹可直接新建索引子页；在画布未编辑文字时按 `⌘V`，会自动识别网页链接、普通文字和库内文件路径。
- **PDF 阅读体验升级**：支持输入页码直达第 N 页，也可以用方向键、空格 / `Shift + 空格` 翻页；默认普通独立窗口，随时可切全屏，同一附件不会重复开出多个窗口。
- **回收站管理增强**：显示原所属目录、摘要和删除时间，支持单独永久清除或一键清空（放心，只会删除笔记和批注记录，硬盘上的原文件会完整保留）。
- **文件夹主页 & Notebook 增强**：文件夹里的子卡片加上了右键菜单，空文件夹提供快捷新建按钮；Notebook 支持在任意位置插入 Code / Markdown 单元、上下移动、删除、切换类型、清空输出，以及 `Shift + Enter` 运行并跳到下一格。
- **iCloud 状态一眼可见**：折叠状态的附件标题栏也会显示云端/本地状态，并支持一键下载或安全释放当前页未使用的本地缓存。

## 交互修复

- **链接块可以直接点了**：切换模式菜单、卡片按钮和内嵌网页现在都能直接点击交互，不再必须先双击才能点。
- **顶部改名同步磁盘**：在页面顶部改标题现在和侧栏一样，会同步重命名硬盘里的文件夹和原文件，并支持 `⌘Z` 撤销。
- **滚轮不卡死**：选中静态公式块或链接卡片时，滚轮会正常滚动整个画布，不会卡在原地不动。
- **Markdown 链接可点击**：支持按住 `⌘ + 单击` 打开笔记里的链接，也可以切到“链接交互”模式直接点击。
- **退出回收站更顺手**：回收站新增“返回页面”按钮，在侧栏点击当前选中的同一页也可以直接退出回收站。
- **防误删 & 块级复制粘贴**：锁定的内容块现在禁止用 `Delete` 或剪切误删；普通文本框、公式块和多选组支持 `⌘C` / `⌘V` / `⌘X` 复制粘贴。
- **字体面板撤销优化**：通过系统字体面板改字体和字号时，连续调整会合并成一条撤销记录，不再刷满历史栈。
- **其他细节**：区分了“文件引用”和“批注关联”的图标；修复 Notebook 运行期间仍可编辑单元格的冲突。

## 安装与升级提醒

- 退出旧版后下载并安装 **Libere-0.7.0-arm64.pkg**，适用于 **Apple Silicon（M 系列）Mac、macOS 14 及以上**。
- **注意**：从 0.7.0 开始资料库索引格式升级为第 3 版，打开旧资料库会自动兼容升级（旧版本 0.6.x 无法再写入新版格式，建议升级前可顺手留一份备份）。
